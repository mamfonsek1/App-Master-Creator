Qué es esta aplicación

Un aula local para ver el curso Refuerzo Master Creador Lans sin depender de la plataforma original. Los vídeos viven en el disco del equipo, la aplicación los reproduce, recuerda por dónde va cada persona y no necesita conexión a internet.

Qué resuelve

  • Caducidad de la plataforma. El curso se conserva y se puede ver en cualquier momento.
  • Progreso por persona. María, Hylary y Yeisy tienen su propia cuenta y su propio avance.
  • Sin fricción. Se abre como una app de Windows: ventana propia, sin navegador ni terminal.

La contraseña temporal inicial es la misma para las tres. Cámbiala en Ajustes → Cambiar contraseña. Las contraseñas se guardan cifradas con scrypt: nadie puede leerlas, solo restablecerlas.

Primer arranque de la app de escritorio

  1. Abre Aula Lans desde el menú Inicio.
  2. La primera vez pide la carpeta de vídeos: elige C:\Users\Maria\Downloads\Lans Studios\media.
  3. La app la valida (debe contener archivos .mp4 en subcarpetas) y la recuerda.
  4. Inicia sesión con tu cuenta.

Reproducción

  • El progreso se guarda cada 5 segundos y al pausar. Al 90 % la lección se marca como vista.
  • Si cierras a mitad, al volver retoma donde lo dejaste.
  • Atajos: espacio reproducir/pausar, ← y → ±5 s, M silenciar, N siguiente.
  • Una lección vista no se desmarca aunque la vuelvas a reproducir.

Menú de usuario

Bajo tu nombre, en la cabecera:

  • Ajustes de la cuenta: datos, cambio de contraseña y, si eres administradora, gestión de las otras cuentas (crear, restablecer contraseña, eliminar).
  • Modo oscuro: cambia la paleta y se recuerda entre sesiones.
  • Cerrar sesión.

Índice

El enlace Índice de la cabecera (y el de la portada) abre una página dentro de la app con los 10 módulos, las 77 lecciones, su duración y un enlace directo a cada una. No abre un PDF ni una pestaña externa.

Cómo fluye una petición

  1. La página (servidor) pide el curso a CourseRepository, que lo lee una vez y lo cachea.
  2. El progreso se lee de SQLite para la persona de la sesión.
  3. El reproductor pide el vídeo a /api/media/<id>, que exige sesión y responde con Range.
  4. Cada guardado va a PUT /api/progress, que valida el cuerpo con Schema y hace un upsert.
04

App de escritorio

La app de Windows es un envoltorio Tauri: una ventana nativa (WebView2) que apunta a un servidor Next empaquetado dentro de la propia aplicación.

Qué ocurre al abrirla

  1. Lee la configuración de %APPDATA%\com.lans.aula\config.json.
  2. Si falta o la carpeta de vídeos ya no existe, pide elegirla y la guarda.
  3. Elige el puerto (41820 si está libre) y arranca node.exe server.js con el entorno adecuado.
  4. Espera a que el puerto responda (máximo 45 s).
  5. Abre la ventana ajustada al monitor y apunta a http://127.0.0.1:41820.
  6. Al cerrar la ventana, mata el servidor hijo.

Por qué el puerto es fijo

Cookies de sesión y preferencias del webview se guardan por origen. Con un puerto aleatorio en cada arranque, la sesión y el modo oscuro se perderían al cerrar. Por eso se usa 41820 de forma estable; solo cambia si está ocupado, y entonces se guarda el nuevo en la configuración.

Instalación

El instalador es NSIS y se instala por usuario (no pide administrador). No está firmado, así que SmartScreen puede avisar la primera vez: Más información → Ejecutar de todas formas.

Requisitos para compilar

  • Rust (rustup) con el target MSVC.
  • Visual Studio Build Tools con el workload de C++.
  • Node.js en el PATH (se copia node.exe al paquete).
  • WebView2 (viene con Windows 10/11).
05

Datos

Base de datos

SQLite en modo WAL. Tres tablas:

TablaColumnasNotas
usersid, name, username, password_hash, role, created_atusername único sin distinguir mayúsculas
sessionsid, user_id, created_at, expires_atid es el SHA-256 del token; caduca a 30 días
progressuser_id, lesson_id, position_seconds, completed, updated_atClave primaria compuesta; borrado en cascada

Eliminar una cuenta borra sus sesiones y su progreso por clave foránea en cascada.

Modelo de contenido

content/course.json se genera con bun run content:build y se valida contra CourseSchema. Cada lección guarda:

{
  "id": "manicura/01-brocas-para-manicura",
  "moduleId": "manicura",
  "title": "BROCAS PARA MANICURA",
  "position": 1,
  "durationSeconds": 118,
  "bytes": 25906356,
  "file": "6. MANICURA/01 - BROCAS PARA MANICURA.mp4"
}

Progreso

El upsert nunca retrocede el estado: si una lección estaba vista, sigue vista. La posición se redondea a dos decimales y se guarda con la marca de tiempo del último cambio.

Copias de seguridad

Basta con copiar dos cosas:

  • %APPDATA%\com.lans.aula\aula.db — cuentas y progreso.
  • La carpeta media/ — los vídeos.

La configuración (config.json) es prescindible: se regenera al elegir carpeta.

Streaming

La respuesta de vídeo incluye Accept-Ranges: bytes y responde 206 con Content-Range cuando se pide un rango. Sin sesión devuelve 401; con un rango imposible, 416.

09

Problemas frecuentes

La app no abre o se cierra sola

Mira %APPDATA%\com.lans.aula\startup.log. Los motivos habituales:

  • La carpeta de vídeos se movió o renombró → borra config.json y vuelve a abrir para elegirla.
  • El puerto 41820 está ocupado por otro programa → la app usa el siguiente libre y lo guarda.
  • Falta node.exe o la carpeta resources → reinstala.

«No se pudo iniciar el aula»

El diálogo indica el motivo y la ruta del log. Si el log está vacío, reinstala el paquete.

Los vídeos no cargan

  • Comprueba que la carpeta elegida contiene una carpeta por módulo con archivos .mp4.
  • Si moviste los vídeos, borra config.json y vuelve a abrir.
  • Verifica que el archivo existe en la ruta que indica course.json.

SmartScreen bloquea el instalador

Es normal: el instalador no está firmado. Más información → Ejecutar de todas formas.

He olvidado la contraseña

Otra persona con rol de administradora puede restablecerla desde Ajustes → Personas con acceso → Gestionar. Si nadie puede entrar, se puede borrar el usuario de la base con SQLite y volver a crearlo.

Quiero empezar de cero

Cierra la app, borra %APPDATA%\com.lans.aula\aula.db y vuelve a abrir: aparecerá la pantalla de primera cuenta.

Borrar aula.db elimina las cuentas y todo el progreso. Haz copia antes.
10

Mantenimiento

Añadir o reemplazar vídeos

  1. Coloca el archivo en su carpeta de módulo, con el prefijo NN - que le corresponda.
  2. Actualiza content/source-manifest.json si cambia el título o la duración.
  3. Ejecuta bun run content:build: valida que cada lección tiene su archivo y regenera el modelo.
  4. Recompila la app (bun run desktop:build) para que el paquete lleve el modelo nuevo.

Actualizar la aplicación

git pull
bun install
bun run content:build
bun run desktop:build
# instalar el nuevo Aula Lans_x.y.z_x64-setup.exe
